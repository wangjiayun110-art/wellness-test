一个独立的子项目，**零构建、零依赖**，任何静态托管平台都能直接跑。

## 一、5 分钟上线

### A. 腾讯 EdgeOne Pages（国内访问最快，**推荐**）

1. 打开 https://edgeone.ai/pages
2. 「创建项目」→ 选择「上传文件夹」
3. 把整个 `wellness-test/` 目录拖进去（**注意是文件夹本身，不要只拖里面文件**——等下第 5 步会改输出目录）
4. 框架选 **Other**
5. 构建命令留空；**输出目录设为 `wellness-test`** （或者你拖的是 `wellness-test/` 内层就不填）
6. 部署，1 分钟拿到 `*.edgeone.app` 域名

### B. 其他平台速通

| 平台 | 操作 |
|---|---|
| **Vercel** | 推到 GitHub → vercel.com/new → Import → 框架 Other |
| **Netlify** | app.netlify.com/drop → 拖 `wellness-test/` 文件夹 |
| **Cloudflare Pages** | dash.cloudflare.com → Pages → 上传 `wellness-test/` 目录 |

任何改动 → 重新拖一次文件夹就行（没有构建步骤，源文件就是发布版本）。

## 二、变现 3 档路径（详细对比）

### 🌱 方案 A · 软广 + 涨粉（**零风险**）

**适合**：刚起步 / 没有营业执照 / 想先做内容

**步骤**：
1. 网站保持现状（不挂购买链接）
2. 在结果页底部加一行：「想看更系统的调养方案？关注公众号 xxx」
3. 用户扫码关注 → 你在私域推送课程/电子书/咨询
4. 变现：课程 99—999 元 / 电子书 9.9—29.9 元

**合规**：不要承诺"治愈"、"治疗"，所有养生建议注明「请咨询专业医生」

**预期收益**：月 500—5000 元（看流量）

---

### 🛒 方案 B · 联盟营销（**变现最快**）

**适合**：愿意走平台返佣 / 不想管供应链

**申请**：
- **淘宝联盟**（https://pub.alimama.com）：门槛很低，账号+实名即可
- **京东联盟**（https://u.jd.com）：同样低门槛
- **拼多多·多多进宝**（https://duoduojinbao.pinduoduo.com）：门槛低
- **抖音·精选联盟**：需要开通带货权限

**集成步骤**：
1. 拿到每个平台的推广链接生成接口
2. 把 `js/data.js` 里 `buildPurchaseLinks()` 替换成带 PID 的推广链接：

```js
// 原
url: `https://search.jd.com/Search?keyword=${enc}`,
// 改
url: `https://u.jd.com/jda_xxx?keyword=${enc}&pid=你的PID`,
```

**预期收益**：佣金率 5%—30%，客单价 30—200 元
- 100 个测试 → 10 个购买 → 平均客单价 100 元 → 佣金 10% → 单次变现 100 元
- 日测试 1000 → 月变现 1—3 万

**合规**：
- 页面注明「本站含推广链接」
- 不要把"保健食品"说成"能治病"

---

### 🏪 方案 C · 自营电商（**最完整**）

**适合**：有营业执照 / 食品流通许可证 / 想建立品牌

**需要的资质**：
1. 公司营业执照（个体工商户也行）
2. **食品经营许可证**（保健食品 / 食品销售）
3. 如产品宣称"蓝帽子"，需要 **保健食品批准文号**
4. ICP 备案 + 公安备案（如有支付）

**技术**：在 result 页替换链接指向你自己的店铺
- 微店 / 有赞：嵌入购买按钮
- 抖店 / 视频号小店：小程序跳转
- 自建：API 对接你的订单系统

**合规红线**（一个都不能碰）：
- ❌ 承诺「治疗」「治愈」「100%有效」
- ❌ 使用患者案例 / 治愈前后对比
- ❌ 宣称食品有"医疗作用"
- ❌ 隐瞒"保健食品不能代替药物"
- ✅ **必须**写清适用人群、禁忌人群、不适宜人群

**预期收益**：毛利 30%—60%，但要承担库存 + 售后

## 四、SEO / 流量获取建议

### 收录

1. 上线后到 **百度站长平台**（ziyuan.baidu.com）提交 sitemap
2. 同时到 **Google Search Console** 提交
3. sitemap 文件放项目根目录：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://你的域名/</loc><changefreq>weekly</changefreq></url>
  <url><loc>https://你的域名/guide.html</loc><changefreq>monthly</changefreq></url>
  <url><loc>https://你的域名/quiz.html</loc><changefreq>monthly</changefreq></url>
</urlset>
```

### 长尾关键词

`index.html` 标题里已经埋了主要词，但 `guide.html` 是 SEO 重头戏。建议：
- 给每个体质单独建一个 URL（如 `/guide/qixu.html`），方便百度收录
- 每篇配 300—500 字原创解读

### 站外引流

- 知乎：找"中医体质"相关问题，回答里贴测试链接
- 小红书：发"九大体质你是哪种"笔记
- 视频号 / 抖音：拍测试过程录屏

## 五、数据与隐私

本项目**所有数据都在用户浏览器本地**（localStorage）：
- 测试进度 / 结果
- **不上传服务器**（这是优势，但也是限制：无法跨设备同步）

如要做用户体系（同步进度、留存用户）：
- 1 个后端 API（Node/Go/Python 都可以）
- 加注册 / 微信扫码登录
- 个人信息要符合《个人信息保护法》（PIPL）

**最小可行**：
- 用腾讯云 / Cloudflare Workers 做一个统计 API
- 只收集："今日测试人数"、"体质分布"，不收集个人信息

## 八、常见问题

**Q：31 道题够不够准？**
A：标准量表是 60+ 题，31 道做的是简化版。结果可以参考但不能作为诊断。建议在结果页加一句「本结果基于 31 题简化版，如需更详细请咨询中医师」。

**Q：怎么加分享裂变？**
A：结果页加「生成你的体质海报」（html2canvas）分享到朋友圈。可以找人做或用现成的 H5 工具。

**Q：能不能加付费测（详细版）？**
A：能。把 31 道免费分成 15 道进阶版（解锁测试需要 9.9 元），用微信小程序支付或 H5 支付。

**Q：怎么换 log？**
A：搜 `<link rel="icon"` 在每个 html 顶部，替换为你的 SVG。
